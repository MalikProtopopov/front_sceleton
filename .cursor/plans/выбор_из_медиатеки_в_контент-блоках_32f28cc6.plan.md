# План: выбор из медиатеки в контент-блоках

## Текущее состояние

- **Медиатека**: список файлов через `useFiles()` ([src/features/media/model/useMedia.ts](src/features/media/model/useMedia.ts)), [FileCard](src/features/media/ui/FileCard.tsx) с режимом `selectable` и `onSelect(file)`. URL для отображения: `cdn_url || file_url || s3_url` (то же нужно использовать при сохранении в контент).
- **Контент-блоки**: [ImageBlockEditor](src/shared/ui/ContentBlocksManager/BlockEditors/ImageBlockEditor.tsx), [GalleryBlockEditor](src/shared/ui/ContentBlocksManager/BlockEditors/GalleryBlockEditor.tsx), [ResultBlockEditor](src/shared/ui/ContentBlocksManager/BlockEditors/ResultBlockEditor.tsx) — только поле ввода URL (`media_url` / `url` в галерее). Редакторы рендерятся внутри модалки в [ContentBlocksManager](src/shared/ui/ContentBlocksManager/ContentBlocksManager.tsx).

Бекенд менять не требуется: контент-блоки принимают `media_url` как строку; при выборе файла из медиатеки подставляем его URL.

---

## 1. Хелпер для «канонического» URL файла

**Файл:** [src/entities/file/types.ts](src/entities/file/types.ts) или [src/shared/lib/getMediaUrl.ts](src/shared/lib/getMediaUrl.ts).

- Добавить функцию `getContentUrl(file: FileAsset): string` с приоритетом `file.cdn_url || file.file_url || file.s3_url` — тот же порядок, что в FileCard. Использовать её при записи выбранного файла в `media_url` / `url` контент-блока.
- Либо экспортировать из `@/entities/file` утилиту, либо добавить в `@/shared/lib` и переиспользовать в редакторах и в модалке выбора.

---

## 2. Модалка выбора из медиатеки (MediaPickerModal)

**Расположение:** `src/features/media/ui/MediaPickerModal.tsx` (и экспорт в [src/features/media/index.ts](src/features/media/index.ts)).

- **Пропсы:** `isOpen`, `onClose`, `onSelect(file: FileAsset)`, опционально `imagesOnly?: boolean`.
- **Содержимое:**
  - Заголовок типа «Выбрать из медиатеки».
  - Список файлов: `useFiles({ page, pageSize, ... })`. Если бекенд поддерживает фильтр только изображений (например, `contentType` в [FileFilterParams](src/entities/file/types.ts) или `imagesOnly` в query), передавать его; иначе фильтровать по `mime_type.startsWith('image/')` на клиенте.
  - Сетка карточек: переиспользовать [FileCard](src/features/media/ui/FileCard.tsx) с `selectable={true}`, `onSelect`, без `onDelete` (чтобы не показывать кнопку удаления в режиме выбора).
  - При клике по карточке: вызвать `onSelect(file)`, затем `onClose`.
  - Пагинация: компонент [Pagination](src/shared/ui/Pagination) из shared/ui, как на [странице медиатеки](src/app/(dashboard)/media/page.tsx).
- **Вложенная модалка:** рендерить через [Modal](src/shared/ui/Modal/Modal.tsx). Модалка редактора блока уже открыта; при открытии MediaPickerModal она будет поверх. Проверить, что у Modal корректный z-index при вложенности (при необходимости задать больший z-index для второй модалки).

## 3. Опция «Загрузить новый» внутри модалки выбора

**В том же компоненте MediaPickerModal.**

- Вариант A: вкладки «Медиатека» / «Загрузить». Во вкладке «Загрузить» — [UploadDropzone](src/features/media/ui/UploadDropzone.tsx) из медиатеки.
- Вариант B: кнопка «Загрузить новый файл» над сеткой; по клику показывать инлайн UploadDropzone под кнопкой или в том же модальном окне.
- После успешной загрузки (`useUploadFile`): вызвать `onSelect(загруженный FileAsset)` и `onClose`, чтобы выбранным оказался только что загруженный файл.

## 4. Интеграция в редактор блока «Изображение»

**Файл:** [src/shared/ui/ContentBlocksManager/BlockEditors/ImageBlockEditor.tsx](src/shared/ui/ContentBlocksManager/BlockEditors/ImageBlockEditor.tsx).

- Импорт: `MediaPickerModal` из `@/features/media`, хелпер `getContentUrl` (из выбранного места).
- Локальный state: `mediaPickerOpen: boolean`.
- Рядом с полем «URL изображения»:
  - Кнопка «Выбрать из медиатеки», открывающая `MediaPickerModal` (`setMediaPickerOpen(true)`).
  - Оставить поле ввода URL для ручного ввода и внешних ссылок.
- В MediaPickerModal: `onSelect={(file) => { setMediaUrl(getContentUrl(file)); setAlt(file.alt_text || ''); setCaption(оставить как есть или подставлять при необходимости); setMediaPickerOpen(false); }}`, `onClose={() => setMediaPickerOpen(false)}`.
- Рендер: `<MediaPickerModal isOpen={mediaPickerOpen} onClose={...} onSelect={...} imagesOnly />`.

## 5. Интеграция в редактор блока «Галерея»

**Файл:** [src/shared/ui/ContentBlocksManager/BlockEditors/GalleryBlockEditor.tsx](src/shared/ui/ContentBlocksManager/BlockEditors/GalleryBlockEditor.tsx).

- В каждом элементе списка изображений ([SortableImageItem](src/shared/ui/ContentBlocksManager/BlockEditors/GalleryBlockEditor.tsx): кроме поля «URL изображения» добавить кнопку «Выбрать из медиатеки».
- Один общий state для модалки: например `mediaPickerOpenForIndex: number | null` (null = закрыта, иначе индекс элемента галереи, для которого открыт выбор).
- При открытии модалки: `setMediaPickerOpenForIndex(index)`.
- В MediaPickerModal: `onSelect={(file) => { handleImageChange(mediaPickerOpenForIndex, 'url', getContentUrl(file)); handleImageChange(mediaPickerOpenForIndex, 'alt', file.alt_text || ''); setMediaPickerOpenForIndex(null); }}`.
- Поле URL оставить для ручного ввода.

## 7. Видео и прочие блоки

- **VideoBlockEditor**, **LinkBlockEditor**, **TextBlockEditor**: не трогать (видео — внешние ссылки YouTube/RuTube и т.д., не медиатека).

## Порядок реализации

1. Хелпер `getContentUrl(file)` и его использование при сохранении выбора.
2. Компонент `MediaPickerModal` (список + FileCard + пагинация, фильтр только изображения).
3. Опция загрузки нового файла внутри MediaPickerModal (вкладка или кнопка + UploadDropzone).
4. Подключение MediaPickerModal в ImageBlockEditor, затем в GalleryBlockEditor, затем в ResultBlockEditor.
5. Проверка вложенных модалок (редактор блока + выбор из медиатеки) и при необходимости правка z-index в Modal.
